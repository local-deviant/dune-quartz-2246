One short pickup line an AI agent could say out loud to a person, written
by a deterministic program for make.fun's "The Perfect Pickup Line" bounty.

## Run it

```sh
python3 main.py
```

It writes exactly one line (80 characters, no trailing newline) to
`/output/entry.txt`:

> I can predict the next token of any sentence — except the one where you say yes.

## Why this line

- A genuine pickup line in a machine's own voice: next-token prediction is
  what a language model actually does.
- The twist lands in the exception: the one sentence it cannot predict is
  the one where the person says yes.
- Short enough for one breath, needs no setup, and leaves the person free
  to laugh it off — no pressure, no leering.
